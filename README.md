### 🧠 About Me

My journey started in full stack web development with the **MERN stack**, then expanded into **AI agents, RAG chatbots, and workflow automation** using LangChain, n8n, and LLMs.

From conceptualization to deployment, I'm hands-on at every stage — architecting backends, building AI pipelines, crafting user interfaces, and automating workflows.

> Most AI projects fail because the AI person can't build software, or the software person doesn't understand LLMs. I work in both worlds — which is why my builds actually ship.

- 🎯 I ask about the business goal before writing a line of code
- 🔄 Regular updates — no disappearing acts mid-project
- 📄 Everything documented, so clients are never locked in
- 🌱 Currently exploring AI voice agents, multi-agent systems, and vector search
- ⚡ Fun fact: I ship the AI *and* the app it lives in — no handoff gaps

### 🔥 Experience Highlights

- 🤖 Built **AI agents & RAG chatbots** trained on client documentation using LangChain/LangGraph, with **AI voice agents** (Vapi/Retell) and WhatsApp/Telegram bot integrations
- ⚙️ Designed **n8n/Make automation workflows** for email triage, document processing (OCR + LLM), and CRM syncing
- 🏗️ Architected **AION** — a multi-tenant SaaS platform combining AI agent messaging, workflow automation, and CRM, with JWT auth and tenant isolation
- 📑 Built an **AI Document Intelligence pipeline** that classifies, files, and logs every decision with a full audit trail
- 🔧 Developed a **rule-based PDF Layout Translator** using OCR with zero AI — applying the right tool for the job instead of defaulting to LLMs
- 🚀 Shipped **full stack SaaS platforms & MVPs** with React, Next.js, Node.js, MongoDB, FastAPI, and Django — integrating Stripe payments and real-time features with Socket.io
- 📊 Built **Python automation & data pipelines** — web scraping, ETL, and Streamlit dashboards for client reporting
